# Blinkit-Dashboard-Power-BI-
![Alt Text](https://github.com/tasnia-sunehara/Blinkit-Dashboard-Power-BI-/blob/main/Blinkit.png)

### Short Description

The Blinkit Sales Dashboard is an interactive business intelligence tool designed to monitor retail performance across different outlets, item categories, and locations. It provides decision-makers with insights into sales, outlet performance, and customer ratings, making it easier to identify opportunities, optimize store operations, and improve product strategy.

### Tech Stack

This dashboard was developed using:

* **📊 Power BI Desktop** – Core tool for interactive data visualizations.
* **📂 Power Query** – Used for data cleaning, transformation, and preparation.
* **🧮 DAX (Data Analysis Expressions)** – For creating custom KPIs, measures, and calculated fields.
* **📝 Data Modeling** – Relationships built between fact and dimension tables (Items, Outlets, Locations, Sales).
* **📁 File Format** – .pbix for live dashboard, .png for static snapshots.

### Data Source

**Source**: Blinkit Retail Dataset (sample dataset for outlet-level sales analysis).
The dataset contains detailed information on items, outlet types, fat content, sales, and customer ratings. Data is structured with:

* **Fact Table** – Sales, Items, Ratings.
* **Dimension Tables** – Outlet Type, Location, Item Category, Outlet Size, Establishment Year.


### Features / Highlights

**Business Problem**
Retail outlets often struggle to analyze which store sizes, product types, or regions generate maximum revenue. Without structured reporting, it’s difficult to compare outlet categories, monitor sales efficiency, and evaluate product demand.

**Dashboard Goal**
To deliver a unified view of retail performance that helps:

* Track total sales, average sales, and number of items sold.
* Compare outlets by location, size, and establishment year.
* Identify sales contribution by item type and fat content.
* Support retail managers in strategy, inventory planning, and outlet expansion.

### Business Impact & Insights

* **📈 Performance Tracking** – Allows monitoring of outlet-level sales, item demand, and customer ratings.
* **🏪 Outlet Strategy** – Reveals that **Tier 3 outlets and medium-sized stores** contribute the most to revenue.
* **🥦 Product Analysis** – Highlights high-performing categories like fruits, snacks, and household items.
* **🍽 Consumer Preferences** – Sales split shows stronger demand for regular fat items.
* **🗓 Long-Term Planning** – Outlet establishment year trends help evaluate the growth pattern of retail operations.
